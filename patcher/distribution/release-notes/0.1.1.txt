Universal Patcher is offered only where The Sims 4 runs: Windows and Linux on x64 computers, and macOS on Intel and Apple silicon. The installers say so plainly on anything else.

The website shows your download right away on Windows and Linux; only a Mac is asked whether it is Intel or Apple silicon.

Windows: saving files, recovering an interrupted update and detecting damaged files now work on Windows disks. The Windows build is included for testing and is not yet offered as verified.
